# Bisho IDE Package 18 – Calm Flat UI

## واجهة Package 18
- إزالة مؤثرات 3D والنيون والتوهج من شاشة البداية ولوحة الأدوات.
- اعتماد خلفية داكنة هادئة وبطاقات مسطحة وحدود خفيفة وزوايا مستديرة.
- توحيد الألوان الأساسية حول الأزرق السماوي والأخضر الهادئ والعنبر للتنبيهات والإجراءات.
- تقليل زمن شاشة البداية واستبدال الحركة الارتدادية بحركة دخول بسيطة.
- الإبقاء على معالجات الأزرار الحالية ووظائف المشاريع والحفظ والتصدير والتبويبات والمعاينة دون تغيير مقصود.

## سياسة التكلفة
- لم تتم إضافة أي dependency أو API أو خدمة خارجية في هذه الحزمة.
- لا توجد إضافة لاشتراكات أو فواتير أو خدمات مدفوعة.
- بقيت قائمة dependencies كما هي في Package 17.

## البناء
استخدم سير عمل GitHub Actions الحالي عبر Klencod، ثم افحص APK على الجهاز قبل اعتماد الحزمة نهائياً.
