# Bisho IDE Package 20 — Mobile Symbol Bar

## Changes
- Added a horizontal mobile coding symbol bar to the full-screen editor.
- Added paired bracket/quote insertion with cursor placement between the pair.
- Selected text is wrapped by paired symbols.
- Added common coding tokens: braces, brackets, semicolon, colon, assignment, arrow, dot, comma, logical operators and indentation.
- Added unit tests for symbol insertion behavior.
- No new package dependencies or paid services.

## Notes
The symbol bar is shown in the full-screen code editor. Tap a symbol to insert it at the current cursor or wrap selected text. The cursor position is preserved after insertion; tap the editor to reopen the on-screen keyboard if Android hides it when the symbol bar is tapped.
