# Bisho IDE Package 65 — Integrated Project Terminal

- Added an integrated terminal panel inside the IDE bottom panel.
- Added toolbar and menu shortcuts to open the terminal.
- Connected terminal navigation and file operations to the active SAF project.
- Added commands: `help`, `pwd`, `ls`, `cd`, `tree`, `cat`, `mkdir`, `touch`,
  `echo ... > file`, `rm`, `open`, `clear`, `date`, `whoami`, and `project`.
- Added command history with Up/Down keys and bounded output history.
- Recursive deletion is disabled. Arbitrary host shell execution is not enabled.
